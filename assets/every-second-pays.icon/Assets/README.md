# Twemoji artwork

`money-with-wings.svg` is the Twemoji “Money with Wings” artwork (U+1F4B8),
from [jdecked/twemoji](https://github.com/jdecked/twemoji), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The `money-bill`,
`money-band`, and `money-wing-*` files split that artwork into four depth
layers for Apple Icon Composer.
