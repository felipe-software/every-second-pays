Flags from [Circle Flags](https://github.com/HatScripts/circle-flags), under the included MIT license. Downloaded from the `gh-pages` branch on 2026-09-13.

SVG files are the original source assets. The 72×72 PNG exports are used by SwiftUI menu icons, which accept UIImage data; `@3x` keeps the intended size at 24 points. Regenerate on macOS with `sips -s format png --resampleHeightWidth 72 72 <country>.svg --out <country>@3x.png`.
